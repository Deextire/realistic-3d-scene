# Realistic Lighting Scene

A lightweight Three.js study featuring:
- realistic sunlight and shadow rendering
- bloom post-processing
- volumetric-inspired sun rays
- natural grass and tree placement
- atmospheric fog and soft color grading

## Run locally

Use any local static server:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Files

- `index.html`
- `style.css`
- `main.js`
